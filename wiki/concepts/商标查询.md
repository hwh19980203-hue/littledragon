# 商标查询

## 概述

商标查询是判断产品/品牌是否侵犯他人商标权的基础步骤，也是跨境电商 TRO 风险排查的重要环节。

## 美国商标查询（USPTO）

### USPTO Trademark Search（TESS 已退役）
- **网址**：https://tmsearch.uspto.gov
- **检索方式**：
  - **Basic Word Mark Search** — 按商标名称检索（新手推荐）
  - **Serial/Registration Number Search** — 按申请号/注册号查询
  - **Owner Name Search** — 按权利人查询

> TESS 已于 2023-11-30 退役，由现行 Trademark Search 取代。官方联邦数据库不包含所有普通法/未注册商标，因此还需搜索实际商业使用、州级登记、平台店铺、域名和商业外观证据。

### TSDR 系统（商标状态与文件查询）
- **网址**：https://tsdr.uspto.gov
- **功能**：查看商标详细状态与法律文件

### 商标状态解读

| 状态 | 含义 |
|------|------|
| REGISTERED | 已成功注册 |
| LIVE APPLICATION | 申请审查中 |
| PUBLISHED FOR OPPOSITION | 已公告，30 天异议期 |
| ABANDONED | 已被放弃或驳回 |
| CANCELLED | 已被注销 |

### 实用技巧
- 需检索发音、含义近似的商标（不仅查同名）
- 美国采用**尼斯分类**（共 45 类），需正确选择对应类别
- 图形商标可上传图像或使用 Design Codes 检索
- 同时检索拼写变体、发音近似、翻译/音译、复数和词序变化
- 跨类别监控：如食品品牌需同步监控第 30 类（调味品）和第 35 类（销售服务）

## 中国商标查询（CNIPA）

| 系统 | 网址 | 说明 |
|------|------|------|
| **中国商标网** | https://sbj.cnipa.gov.cn | 2025 年起需注册登录 |
| **商标近似查询** | wcjs.sbj.cnipa.gov.cn | 申请前预查 |
| **商标综合查询** | 同上 | 按商标号/名称/申请人查询 |
| **商标状态查询** | 同上 | 跟踪审查进度 |
| **商标公告查询** | 同上 | 查阅电子公告 |

> 收录 1980 年至今全部商标数据，每日更新，免费查询。

## WIPO 国际商标查询

- **马德里体系**：通过 WIPO 全球品牌数据库查询国际商标
- 网址：https://www.wipo.int/branddb/
