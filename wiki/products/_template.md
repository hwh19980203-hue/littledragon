## 最终判断

### 完整性门禁

- [ ] 所有 `review_markets` 已检索，或未检范围已明确披露
- [ ] 必查数据库均可访问；失败项已保持 `unknown`
- [ ] 候选权利的状态、权利人、期限、目标市场覆盖已核实
- [ ] 视觉相关结论已达到 `human-verified` 或 `vision-verified`
- [ ] TRO 状态已区分 complaint / motion / granted / active / expired-vacated-dismissed
- [ ] 产品 SKU、包装与 Listing 素材版本已冻结；变更会触发增量复审
- [ ] 检索仍在 `valid_until` 内

> 任一必要项未勾选：保持 `status: in-review`、`risk_level: unknown`，不得选择 Go。

- [ ] **Go** ✅ — 可安全上架（cleared）
