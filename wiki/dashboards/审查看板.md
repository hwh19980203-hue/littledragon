# 产品审查看板

> 实时展示所有产品的审查状态

---

## 待审核（Pending）

```dataview
TABLE product as "产品", risk_level as "风险", created as "建档日期"
FROM "wiki/products"
WHERE status = "pending"
SORT created ASC
```

## 审查中（In Review）

```dataview
TABLE product as "产品", reviewer as "审核人", target_markets as "市场"
FROM "wiki/products"
WHERE status = "in-review"
SORT updated DESC
```

## 已通过（Cleared）

```dataview
TABLE product as "产品", updated as "审核完成"
FROM "wiki/products"
WHERE status = "cleared"
SORT updated DESC
```

## 高风险（Risky / Blocked）

```dataview
TABLE product as "产品", risk_level as "风险等级", patents_found as "相关专利"
FROM "wiki/products"
WHERE status = "risky" OR status = "blocked"
SORT risk_level ASC
```

---

## 按风险等级统计

```dataview
TABLE length(rows) as "数量"
FROM "wiki/products"
WHERE status
GROUP BY risk_level
SORT risk_level ASC
```
